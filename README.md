# IPL-Analysis-2008-2025


# **Problem Statement**

The Indian Premier League (IPL) has evolved over 17 seasons, with dynamic team performances, player statistics, and shifting trends. Analyzing this vast dataset manually is challenging. This dashboard aims to provide an interactive and comprehensive view of IPL data from 2008 to 2025, enabling stakeholders to derive insights efficiently.

# **Tools Used**

**Power BI:** For data visualization and dashboard creation.

**DAX:** To implement complex calculations and KPIs.

**Power Query Editor:** For data transformation and cleaning.

# **Solution / Insights**

Developed an interactive Power BI dashboard offering:

**Season-wise Performance Metrics:** Including total runs, wickets, fours, and sixes.

**Team Standings:** Displaying wins, losses, ties, and total points for each season.

**Player Achievements:** Highlighting Orange Cap (Most Runs), Purple Cap (Most Wickets), and other significant statistics.

**Dynamic Filters:** Allowing users to select specific years for detailed analysis.

This dashboard serves as a valuable tool for analysts, team managers, and enthusiasts to explore IPL data interactively.

# **Impact / Key Takeaways**

**Performance Insights:** Identified top-performing teams and players over 17 seasons, helping understand long-term trends in wins, runs, and wickets.

**Strategic Analysis:** Highlighted patterns such as which teams perform better at home grounds or in specific seasons, supporting team strategy planning.

**Player Metrics:** Tracked Orange Cap and Purple Cap trends, helping identify consistently high-performing players and emerging talents.

**Data-Driven Decision Support:** Interactive filters allow quick season-wise or player-wise analysis, reducing manual effort by ~70% compared to raw data analysis.

**Trend Visualization:** Enabled stakeholders and enthusiasts to easily spot scoring trends, team performance changes, and high-impact players, improving insights for reporting or fan engagement.
